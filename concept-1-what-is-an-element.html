CONCEPT 1

What is an element?

LEARNING OBJECTIVE
Define atom and element, and use chemical symbols correctly — including symbols that don't match the English name.
BIG IDEA
An element is a pure substance made of only one type of atom — the smallest part of that element that can exist. Every element has its own symbol, agreed worldwide.

THE BIG QUESTION

If you kept cutting this gold bar in half… would it always still be gold?

THE STORY

~2400 YEARS AGO

Democritus, a thinker in Ancient Greece, imagined matter was made of tiny particles too small to cut any further.

He called them atomos — meaning "uncuttable."

💬 Was he guessing, or did he have evidence?

~200 YEARS AGO

John Dalton gave every element its own circular symbol — a different mark for every element.

TODAY

Scientists agreed on one- or two-letter symbols instead — quicker to write, understood worldwide.

H O C Fe Au Ag

Some symbols match the English name:

✓ Hydrogen = H
✓ Carbon = C

Others don't:

✓ Gold = Au (aurum) ✕not G
✓ Sodium = Na (natrium) ✕not S
KW: An atom is the smallest part of an element that can exist. Applied to gold: the smallest part of the element gold that can exist.
KW: An element is a pure substance made of only one type of atom.

COMMON MISCONCEPTIONS

✕ Every element's symbol is just its first English letter — even common ones like iron (Fe) and sodium (Na) come from Latin names instead.
✕ "Atom" and "element" mean the same thing — an atom is one particle; an element is the substance made of that one type of atom.
